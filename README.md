# Dr. Maher Khalaf Hussein — Personal Website

## Before publishing

1. Add your personal photo to this folder and name it `profile.jpg`.
2. Replace `your-email@example.com` in `index.html` with your real email address.
3. Replace the placeholder links in the contact section if you want to add Google Scholar, ORCID, or GitHub.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, `favicon.svg`, `README.md`, and `profile.jpg`.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder, then click **Save**.

The website will be available at `https://your-username.github.io/repository-name/`.
